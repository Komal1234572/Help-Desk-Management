# Help Desk Management System

A full-stack ticket management application built to streamline support requests and provide a centralized system for managing help desk operations.

### Key Features

* User Registration & Login
* Admin Dashboard
* Create, View, Update & Delete Tickets
* Ticket Status Filtering
* RESTful API
* Unit Testing

### Built With

**Backend:** C#, ASP.NET Core Web API, Entity Framework Core
**Frontend:** ASP.NET Core MVC, Razor, HTML, CSS
**Database:** Microsoft SQL Server
**Testing:** .NET Unit Testing

### Architecture

```text
ASP.NET Core MVC
        ↓
    REST API
        ↓
 Entity Framework Core
        ↓
 Microsoft SQL Server
```
